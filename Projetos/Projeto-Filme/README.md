# Landing Page — Filme

Projeto desenvolvido como exercício do Módulo 21 da EBAC.

## Sobre

Landing page temática de Star wars, com seções de sinopse, elenco, trailer e galeria de imagens.

## Tecnologias

- HTML5
- Sass (SCSS)
- Gulp (compilação do Sass)

## Como rodar localmente

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Compile o CSS:
   ```bash
   npx gulp
   ```

3. Para recompilar automaticamente ao salvar:
   ```bash
   npx gulp watch
   ```

4. Abra o `index.html` no navegador.

> A pasta `css/` é gerada pelo Gulp e não está no repositório. Rode o passo 2 antes de abrir o projeto.
