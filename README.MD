Exercício – Boas Práticas de CSS (Metodologia BEM)

Este projeto foi desenvolvido como parte do módulo de **Boas Práticas de CSS** do curso Full Stack Python – EBAC.

Objetivo:
   Aplicar a metodologia **BEM (Block, Element, Modifier)** para melhorar a organização, reutilização e manutenção do código CSS.

Estrutura do Projeto

### HTML
A estrutura do código foi refatorada em blocos, elementos e modificadores:

- **Bloco:** `.product`
- **Elementos:** `.product__image`, `.product__name`, `.product__description`
- **Modificador:** `.product--featured`

### CSS
Foi utilizado um layout **Grid** para organizar os produtos em 3 colunas e aplicar destaque visual ao produto em evidência.

Tecnologias Utilizadas
- HTML5  
- CSS3  
- Metodologia BEM
